# CodSoft Data Analytics Internship

A collection of five practical data analytics projects completed as part of my **CodSoft Data Analytics Internship** using Python and its data analysis libraries.

## Project Overview

This repository demonstrates practical skills in data cleaning, exploratory data analysis, data visualization, customer segmentation, and web data extraction.

## Completed Projects

| Task | Project | Description | Status |
|---|---|---|---|
| 1 | Data Cleaning and Preprocessing | Cleaned customer sales data by handling duplicates, missing values, inconsistent entries, and data types. | Completed |
| 2 | Exploratory Data Analysis (EDA) | Analyzed the Online Retail dataset to identify sales trends, customer patterns, product performance, and business insights. | Completed |
| 3 | Data Visualization Dashboard | Created charts and a combined dashboard to visualize sales trends, product revenue, and country-wise performance. | Completed |
| 4 | Customer Behaviour and Segmentation Analysis | Applied RFM analysis to segment 4,338 customers based on purchasing behaviour. | Completed |
| 5 | Web Data Extraction and Analysis | Scraped 1,000 book records from Books to Scrape using Python Requests and BeautifulSoup. | Completed |

## Technologies and Tools

- **Programming Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib
- **Web Scraping:** Requests, BeautifulSoup
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub
- **Data Format:** CSV, Excel

## Project Highlights

### Task 1 – Data Cleaning
- Original records: 10
- Duplicate records removed: 1
- Final cleaned records: 9

### Task 2 – Exploratory Data Analysis
- Dataset: Online Retail
- Original records: 541,909
- Gross positive sales value: £10,666,684.54
- Unique customers in filtered sales: 4,338

### Task 3 – Data Visualization
- Created five individual visualizations.
- Developed a combined sales dashboard.
- Analyzed monthly trends, top products, country-wise sales, and transaction patterns.

### Task 4 – Customer Analysis
- Cleaned transaction records: 392,692
- Unique customers analyzed: 4,338
- Total customer spending: £8,887,208.89
- Created five customer segments using RFM analysis.

### Task 5 – Web Data Extraction
- Website: https://books.toscrape.com/
- Catalogue pages scraped: 50
- Books extracted: 1,000
- Average book price: £35.07
